# 🧠 Psychologists.services

## 🔗 [Live Demo](https://psychologists-b92s.vercel.app/) | 🎨 [Figma Design](https://www.figma.com/design/I5vjNb0NsJOpQRnRpMloSY/Psychologists.Services?node-id=0-1&p=f&t=BcVXZ9UywJvSEySr-0)

**Psychologists.services** is a modern web application designed to connect users with professional psychologists. The project provides a seamless experience for discovering, filtering, sorting, and booking psychological consultations, built with modern frontend technologies and integrated with Firebase.

## 🚀 Key Features

* **Three Core Pages** — Includes an engaging **Home** page with a company slogan and call-to-action, a fully interactive **Psychologists** catalog, and a private **Favorites** page.
* **User Authentication** — Secure registration, login, data fetching for the current user, and logout functionality powered by **Firebase**.
* **Advanced Sorting & Filtering** — Sort psychologists alphabetically (A to Z, Z to A), by price (lowest to highest, highest to lowest), or by popularity/rating.
* **Pagination & Infinite Loading** — Load psychologists in portions of 3 cards with smooth fetching from the database via a "Load more" button.
* **Detailed Profiles & Reviews** — Expandable cards showing detailed professional specifications, licenses, experience, and client reviews.
* **Interactive Favorites System** — Add or remove psychologists from favorites (secured for authorized users with persistent state storage).
* **Appointment Booking & Notifications** — Fully validated appointment booking form with success notifications via **react-hot-toast**.

## 🛠 Tech Stack

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Backend & Database:** Firebase (Authentication & Realtime Database)
* **Form Management & Validation:** React Hook Form & Yup
* **Styling:** CSS Modules
* **Key Libraries:** Axios (for API requests), React Icons, React Hot Toast
* **Deployment:** Vercel
